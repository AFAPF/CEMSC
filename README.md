# 🖱️⌨️ CEMSC – Centre d’Entraînement Maîtrise Souris & Clavier

**CEMSC** est une application web interactive conçue pour évaluer et améliorer vos compétences en utilisation de la souris et du clavier. Elle propose plusieurs modules de jeux sérieux, avec suivi de progression, badges, classement et sons immersifs.

https://afapf.github.io/CEMSC/

## 🎯 Fonctionnalités

- **4 modules d’entraînement** :
  - 🖱️ **Speed Click** : cibles à cliquer (clic gauche/droit), taille décroissante, combo et vies.
  - ⌨️ **Keyboard Master** : alphabet, accents, ponctuation, raccourcis claviers, mode "All Stars".
  - 🐭 **Atelier Souris** : exercices de clic gauche, clic droit, double‑clic, et **glisser‑déposer**.
  - 📝 **Dactylo** : frappe de texte avec calcul du WPM (mots par minute) et précision.

- **Système de progression** :
  - Niveau et points d’expérience (XP)
  - Badges à débloquer (ex: `Maître du clic gauche`, `Speed Click Niv.5`, `Dactylo Rapide`…)
  - Sauvegarde automatique dans le navigateur (localStorage)

- **Classement global** : top 50 scores tous modules confondus.

- **Profils multiples** : créez ou supprimez des profils, basculez entre joueurs.

- **Retours sonores** : sons distincts pour les actions réussies/ratées dans **Keyboard Master** et **Speed Click**.

- **Heatmap** (Keyboard Master) : visualisation des erreurs par touche.

- **Interface responsive** : s’adapte aux ordinateurs de bureau et tablettes.

## 📦 Installation locale

1. **Téléchargez** le fichier `index.html` (ou clonez le dépôt).
2. **Double-cliquez** sur le fichier : il s’ouvre dans votre navigateur.
3. **Aucun serveur** nécessaire – tout fonctionne en local (JavaScript pur, HTML5, CSS).

### Prérequis
- Navigateur moderne (Chrome, Firefox, Edge, Safari) avec JavaScript activé.
- Autorisation du son (pour les feedbacks audio).

## 🎮 Utilisation

1. À l’accueil, choisissez un module en cliquant sur sa carte.
2. Créez ou sélectionnez un profil via le bouton **👤 Profils**.
3. Chaque module possède ses propres commandes :
   - **Speed Click** : cliquez sur les cibles correspondant au bouton demandé (gauche/droit). Le jeu accélère à chaque niveau.
   - **Keyboard Master** : appuyez sur la touche ou le raccourci affiché avant la fin du timer.
   - **Atelier Souris** : sélectionnez l’exercice, puis interagissez avec les éléments à l’écran.
   - **Dactylo** : recopiez le texte affiché le plus rapidement possible.
4. Terminez une partie pour gagner de l’XP et débloquer des badges.
5. Consultez le **🏆 Classement** pour comparer vos scores.

## 🛠️ Technologies utilisées

- HTML5 / CSS3 (Grid, Flexbox, variables CSS)
- JavaScript ES6 (Canvas, AudioContext, localStorage)
- Stockage local pour les profils, scores et progression
